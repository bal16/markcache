# Games

> Main langsung di browser, menghidupkan ulang klasik lewat port & recomp,
> emulator retro, sampai dunia modding. Catatan untuk port/recomp: file game
> aslinya milikmu sendiri. Proyek di bawah hanya menjalankan ulang file itu.

## Web Games (asli)

- [Konohapoly](https://konohapoly.vercel.app/) — Monopoly bertema Konoha, karya komunitas Indonesia. `board` ⭐
- [Richup.io](https://richup.io/) — Monopoly online, bisa main cepat dengan pemain publik. `board`
- [Friv](https://www.friv.com/) — aggregator game browser klasik; pintu masuk nostalgia. `agregator` ⭐
- [itch.io HTML5](https://itch.io/games/html5) — ribuan game indie web-playable gratis; eksplorasi tanpa ujung. `indie` ⭐
- [PolyTrack](https://www.polytrack.io/) — racing bergaya TrackMania, bisa bagi-bagi track lewat kode komunitas. `racing`
- [Slow Roads](https://slowroads.io/) — driving santai di jalan tanpa ujung, enak buat melepas penat. `racing`
- [Road Rash](https://roadrash.pages.dev/) — adaptasi web tidak resmi classic EA racing. `racing`
- [Drifted](https://www.drifted.com/) — koleksi game drifting di browser. `racing`
- [Beyond All Reason](https://www.beyondallreason.info/) — RTS open-source kelas Supreme Commander; gratis selamanya. `rts` ⭐

## Port & Recomp

Butuh file game aslinya sendiri (disc/ROM). Proyek ini menjalankan ulang file tersebut, bukan membagikan isinya.

- [SpeedBreaker](https://github.com/SpeedBreakerProject/speedbreaker) — static recompilation NFS Most Wanted 2005 (Xbox 360) ke PC. `recomp` ⭐
- [NFSU2 Recompiled](https://github.com/codepdbh/nfsu2-recompiled) — static recompilation Need for Speed Underground 2 ke x86-64. `recomp`
- [OpenNFS](https://github.com/OpenNFS/OpenNFS) — rekreasi open-source NFS klasik (1-6), membaca file data game asli. `engine`
- [Ship of Harkinian](https://www.shipofharkinian.com/) — port Ocarina of Time ke PC: resolusi & frame rate bebas. `port` ⭐
- [Zelda 64: Recompiled](https://github.com/Zelda64Recomp/Zelda64Recomp) — static recompilation Majora's Mask untuk PC. `recomp`
- [ioquake3](https://github.com/ioquake/ioq3) — Quake III source port; fondasi banyak game kompetitif lanjutan. `engine`
- [Awesome Unofficial PC Ports](https://github.com/Sebastrion/awesome-unofficial-pc-ports) — indeks port tidak resmi terkurasi GitHub. `index`
- [PCGamingWiki Ports](https://www.pcgamingwiki.com/wiki/List_of_unofficial_ports) — daftar port tidak resmi, dikelola wiki PCGaming. `index`

## Retro & Emulator (browser)

Koleksi di sini dijalankan dari arsip Internet Archive. Untuk self-hosting sendiri: [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) (library emulasi JS, mudah disematkan).

- [DOS Zone](https://dos.zone/) — mainkan game DOS klasik di browser, koleksi siap pakai. `dos` ⭐
- [Console Living Room](https://archive.org/details/consolelivingroom) — arsip console retro resmi Internet Archive, main langsung. `retro` ⭐
- [EmulatorJS](https://demo.emulatorjs.org/) — demo emulator lintas konsol yang bisa di-embed di web mana pun. `selfhost` ⭐
- [webЯcade](https://play.webrcade.com/) — frontend retro untuk browser & TV, sangat ringan. `retro`
- [RetroArch Web](https://web.libretro.com/) — RetroArch berjalan di browser. `retro`
- [Play Classic Games](https://playclassic.games/) — konsol retro via multi-emulator browser. `retro`

## Modding

- [Nexus Mods](https://www.nexusmods.com/) — hub modding terbesar dunia: Skyrim, Baldur's Gate 3, dsb. `hub` ⭐
- [ModDB](https://www.moddb.com/) — arsip mod klasik era Half-Life + total conversion. `hub` ⭐
- [CurseForge](https://www.curseforge.com/) — mod & modpack Minecraft, platform paling populer. `minecraft`
- [FabricMC](https://fabricmc.net/) — mod loader Minecraft ringan untuk versi terkini. `minecraft` ⭐
- [GameTechWiki](https://emulation.gametechwiki.com/index.php/Game_engine_recreations_and_source_ports) — wiki source ports & engine recreations; rujukan komunitas. `referensi`
