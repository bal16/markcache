# AI Tools

> Kurasi alat AI gratis/open-source: chat (web & lokal), search AI, gambar, audio/TTS, dan coding. Hanya yang punya tier gratis nyata.

## Chat Gratis (Web)

- [DeepSeek](https://chat.deepseek.com/) — V4.1 Flash, unlimited, no phone. `chat` ⭐
- [Qwen](https://chat.qwen.ai/) — Qwen3.8 Max, clear cookies reset limit. `chat` ⭐
- [Z.ai](https://chat.z.ai/) — GLM 5.3, agent + slide generator. `chat`
- [Google AI Studio](https://aistudio.google.com/app/prompts/new_chat) — Gemini Flash/Pro preview, dev-first. `chat` ⭐
- [NVIDIA NIM](https://build.nvidia.com/models) — multi-model, unlimited, no sign-up. `chat`
- [Ecosia AI](https://www.ecosia.org/ai-chat) — Mistral Small, unlimited, privacy-friendly. `chat`
- [Apertus](https://publicai.co/chat) — Apertus v1.5 70B, ALIA 40B (Spain), no sign-up. `chat`

## Multi-Model & Search AI

- [Together.ai](https://chat.together.ai/) — GLM-5.3, Kimi K3, Qwen, DeepSeek V4 Pro; 110/day. `multi` ⭐
- [Tryingopen](https://www.tryingopen.com/) — DeepSeek V4, Qwen3.8, GLM-5.3; unlimited 12/chat. `multi`
- [Brave Ask](https://search.brave.com/ask) — AI search engine, no sign-up. `search` ⭐
- [Perplexity](https://www.perplexity.ai/) — AI search + sumber, fitur upgrade ada. `search`
- [Exa](https://exa.ai/search) — AI search untuk dev/research. `search`
- [Google AI Mode](https://google.com/aimode) — AI mode Google, 5/day pro. `search`

## Local LLM (Desktop / WebUI)

- [LM Studio](https://lmstudio.ai/download) — desktop app, load model GGUF mudah. `local` ⭐
- [Ollama](https://ollama.com/) — CLI + API lokal, `ollama run llama3`. `local` ⭐
- [Jan](https://jan.ai/) — desktop open-source alternatif LM Studio. `local`
- [Open WebUI](https://openwebui.com/) — self-hosted web UI, docker siap pakai. `local` ⭐
- [SillyTavern](https://docs.sillytavern.app/) — desktop roleplay/character, banyak preset. `roleplay` ⭐
- [GPT4All](https://www.nomic.ai/gpt4all) — desktop, model quantized ringan. `local`
- [TextGen WebUI](https://github.com/oobabooga/textgen) — web UI klasik untuk model HF. `local`
- [llamafile](https://github.com/Mozilla-Ocho/llamafile) — single-file executable LLM. `local`
- [Can I Run This LLM?](https://llmrun.dev/) — cek model mana yang muat di RAM/VRAM kamu. `tools`

## Fine-Tuning & Self-Host Tools

- [Unsloth](https://unsloth.ai/) — fine-tune LLM hemat VRAM, notebook siap pakai. `finetune` ⭐
- [llama.cpp](https://llama.app/) — inference engine C++ paling populer. `engine` ⭐
- [KoboldCpp](https://github.com/LostRuins/koboldcpp) — llama.cpp + API + GUI. `engine`
- [LocalAI](https://localai.io/) — drop-in replacement OpenAI API untuk model lokal. `engine`
- [Stability Matrix](https://lykos.ai/) — manajer model Stable Diffusion, update otomatis. `image` ⭐

## Image Generation

- [ComfyUI](https://www.comfy.org/) — node-based pipeline paling fleksibel. `image` ⭐
- [Fooocus](https://github.com/lllyasviel/Fooocus) — SDXL sederhana, "install & generate". `image` ⭐
- [InvokeAI](https://invoke.ai/) — professional UI untuk SD, support lora/controlnet. `image`
- [Civitai](https://civitai.com/) — model & LoRA index terbesar. `models` ⭐
- [Pinokio](https://pinokio.co/) — one-click install banyak AI app (NVIDIA only). `tools`
- [A Traveler's Guide to Latent Space](https://sweet-hall-e72.notion.site/A-Traveler-s-Guide-to-the-Latent-Space-85efba7e5e6a40e5bd3cae980f30235f) — panduan AI art mendalam. `guide` ⭐

## Audio & TTS

- [Suno](https://suno.com/) — generate lagu lengkap (lirik+vokal), 10/hari gratis. `audio` ⭐
- [Stable Audio](https://www.stableaudio.com/) — music generation, 10/bulan. `audio`
- [MusicGen](https://github.com/facebookresearch/audiocraft/blob/main/docs/MUSICGEN.md) — Meta, no sign-up, Colab ready. `audio`
- [ElevenLabs](https://elevenlabs.io/) — TTS paling natural, tier gratis terbatas. `tts`
- [Kokoro TTS](https://huggingface.co/spaces/hexgrad/Kokoro-TTS) — TTS open-source ringan, no sign-up. `tts` ⭐
- [Fish Audio](https://fish.audio/) — TTS + voice clone, web UI bersih. `tts`
- [Ebook2Audiobook](https://github.com/DrewThomasson/ebook2audiobook) — konversi EPUB/PDF ke audiobook. `tools`
- [IOPaint](https://www.iopaint.com/) — inpainting/removal gambar, juga bisa audio cleanup. `tools`
