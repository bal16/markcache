# Student Deals

> Manfaat dan tool gratis untuk pelajar & mahasiswa. Mayoritas butuh verifikasi
> status kampus (email edukasi, KTM, kartu pelajar digital). Sebagian aktif
> hanya selama masa studi, jadi klaim sejak tahun pertama biar tak hangus.

## Bundel & Klaim Utama

- [GitHub Student Developer Pack](https://education.github.com/pack) — bundel terbesar: Copilot, domain gratis, credit cloud, dan puluhan mitra. `bundel` ⭐
- [GitHub Copilot Pro](https://docs.github.com/en/copilot/how-tos/manage-your-account/get-free-access-to-copilot-pro) — Copilot Pro gratis untuk mahasiswa verifikasi. `ai-coding` ⭐
- [Zed Student Plan](https://zed.dev/education) — editor Zed Pro gratis 1 tahun, termasuk kredit token AI $10/bulan. `editor` ⭐
- [Gemini for Students](https://gemini.google/students/) — kredit Gemini gratis untuk mahasiswa universitas terdaftar. `ai`
- [Azure for Students](https://azure.microsoft.com/free/students/) — $100 credit Azure tanpa kartu kredit, butuh email kampus. `cloud`
- [Heroku for Students](https://www.heroku.com/students/) — kredit bulanan $13 selama aktif kuliah, untuk deploy app. `deploy`
- [Notion Education](https://www.notion.com/students) — plan Plus gratis untuk akun kampus. `produktivitas`

## Learning Gratis

- [JetBrains Education](https://www.jetbrains.com/community/education/) — semua JetBrains IDE gratis selama menempuh pendidikan. `ide` ⭐
- [GitHub Classroom](https://classroom.github.com/) — playground assignment & tugas kampus via repo GitHub. `belajar`
- [DigitalOcean Credit](https://www.digitalocean.com/github-students) — credit $200 untuk mahasiswa via GitHub Student Pack. `cloud`

## Tips Klaim

> Simpan email kampus kamu dengan rapi. Hampir semua vendor mengirim link
> verifikasi ke sana. Klaim satu per satu sebelum masa studi berakhir.
> Sejumlah paket pasca-kuliah tidak bisa diperpanjang.
