# Self-Hosted

> Aplikasi yang dijalankan di server sendiri, baik di VPS maupun mesin
> rumahan. Kumpulan ini fokus pada layanan yang punya tier gratis penuh atau
> open source. Untuk alat deploy dan panel manajemen container, lihat
> [Dev Tools](/devtools#hosting-deploy).

## Catatan & Dokumen

- [UseMemos](https://usememos.com/) — catatan ringan self-host berbasis Markdown dengan API sederhana. `notes` ⭐
- [Paperless-ngx](https://paperless-ngx.com/) — arsip dokumen dengan OCR dan pencarian teks penuh. `dokumen`
- [Trilium Notes](https://triliumnotes.org/) — catatan hierarkis dengan sinkronisasi dan enkripsi end-to-end. `notes`
- [BookStack](https://www.bookstackapp.com/) — wiki dokumentasi berbasis buku dan rak. `wiki`
- [Wiki.js](https://wiki.js.org/) — wiki modern berbasis Node.js dengan editor visual. `wiki`

## Foto & Media

- [Immich](https://immich.app/) — backup foto dan video self-host ala Google Photos dengan pengenalan wajah. `foto` ⭐
- [PhotoPrism](https://www.photoprism.app/) — galeri foto self-host dengan pencarian cerdas berbasis AI. `foto`
- [Photoview](https://photoview.github.io/) — galeri foto dan video sederhana yang ringan. `foto`
- [Jellyfin](https://jellyfin.org/) — media server open source untuk film, serial, dan musik. `media` ⭐

## Dashboard & Homelab

- [CasaOS](https://casaos.zimaspace.com/) — dashboard homelab ringan dengan app store one-click. `dashboard` ⭐
- [Homepage](https://gethomepage.dev/) — dashboard service modern dengan widget status dan integrasi. `dashboard`
- [Dashy](https://dashy.to/) — dashboard self-host yang bisa dikustomisasi lewat YAML. `dashboard`
- [Heimdall](https://heimdall.site/) — dashboard aplikasi sederhana untuk kumpulan layanan. `dashboard`

## Monitoring & Ops

- [Uptime Kuma](https://uptime.kuma.pet/) — monitoring uptime dengan notifikasi, mirip UptimeRobot. `monitoring` ⭐
- [Netdata](https://www.netdata.cloud/) — monitoring real-time per mesin dengan dasbor otomatis. `monitoring`
- [Beszel](https://beszel.dev/) — monitoring ringan untuk server dan container. `monitoring`

## Keamanan & Akses

- [Vaultwarden](https://github.com/dani-garcia/vaultwarden) — implementasi Bitwarden kompatibel yang jauh lebih ringan. `password` ⭐
- [Authelia](https://www.authelia.com/) — SSO dan 2FA untuk reverse proxy. `auth`
- [Authentik](https://goauthentik.io/) — IdP modern dengan SSO dan MFA. `auth`

## Dev & Git

- [Gitea](https://about.gitea.com/) — git hosting ringan, alternatif GitHub self-host. `git` ⭐
- [Forgejo](https://forgejo.org/) — fork komunitas Gitea dengan tata kelola terbuka. `git`
- [Woodpecker CI](https://woodpecker-ci.org/) — CI/CD ringan, alternatif Drone. `ci`

## Sinkronisasi

- [Syncthing](https://syncthing.net/) — sinkron file P2P tanpa server pusat. `sync` ⭐
- [Nextcloud](https://nextcloud.com/) — cloud pribadi: file, kalender, kontak. `cloud`
