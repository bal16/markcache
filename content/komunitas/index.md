# Komunitas

> Tempat bertanya soal hal teknis maupun hobi, dan berbagi rilis yang mungkin
> terlewat. Mulai dari forum lokal yang sudah lama hidup sampai server chat yang
> ramai tiap hari. Aturan tiap komunitas berbeda, jadi baca dulu sebelum posting.

## Komunitas Indonesia

- [Kaskus](https://www.kaskus.co.id/) — forum Indonesia besar yang masih aktif; lounge, jual beli, dan diskusi hobi. `forum` ⭐
- [r/indonesia](https://www.reddit.com/r/indonesia/) — salah satu subreddit umum terbesar untuk berita, tanya jawab, dan obrolan sehari-hari. `reddit`
- [r/indonesiadev](https://www.reddit.com/r/indonesiadev/) — subreddit khusus developer Indonesia; lowongan, diskusi stack, dan portofolio. `reddit`
- [Discord Kusonime](https://discord.gg/kusonime) — server Discord komunitas anime Kusonime, tempat rilis dan obrolan. `discord`
- [Telegram Samehadaku](https://t.me/samehadaku) — kanal Telegram Samehadaku untuk notifikasi episode baru. `telegram`

## Forum Global

- [Reddit](https://www.reddit.com/) — forum dengan hampir semua topik; mulai dari pencarian subreddit. `forum` ⭐
- [Hacker News](https://news.ycombinator.com/) — diskusi teknologi dan startup, kurasi lewat suara komunitas. `forum`
- [Lobsters](https://lobste.rs/) — forum tautan programming dengan fokus kualitas diskusi. `forum`

## Chat & Server

- [Discord](https://discord.com/) — server teks, voice, dan thread; hampir semua komunitas punya server. `chat` ⭐
- [Telegram](https://telegram.org/) — kanal dan grup besar, sering dipakai komunitas lokal untuk rilis cepat. `chat`
- [Matrix](https://matrix.org/) — protokol chat terdesentralisasi, bisa di-self-host. `chat`
- [Revolt](https://revolt.chat/) — alternatif Discord open source dengan tampilan ringan. `chat`

## Dev & Open Source

- [GitHub](https://github.com/) — tempat kode, issue, dan diskusi proyek open source. `kode` ⭐
- [Stack Overflow](https://stackoverflow.com/) — tanya jawab pemrograman; jawaban lama masih relevan untuk error umum. `tanya-jawab`
- [Dev.to](https://dev.to/) — blog dan komunitas developer, lebih longgar daripada Stack Overflow. `blog`
